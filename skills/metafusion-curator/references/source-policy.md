# 来源、名称与原始资料

选择实际支持本次事实、别人能复核的资料，优先使用原始出版物、制作方或权利方记录。社区数据库也可以作为来源，注明它具体支持什么；有冲突时保留分歧，不把推测写成已知事实。来源的选择和检索顺序由 Agent 按任务决定，无需按固定等级完成一套认证流程。

工具返回的 `source_qualification`、`level` 和 `field_limits` 是来源背景与使用范围提示，不是编辑权限或提交门槛。连接器的解析限制见[提供方说明](../scripts/tools/README-providers.md)。

提交来源使用 `url` 或 `publication`，citation 说明支持的事实。当前服务端拒绝新增 `self` 和以本站为独立证据的来源；具体格式见[载荷](api-templates.md#请求头与证据)。已有历史来源不需要为普通修改重写。

## 中文译名

中文题名和别名采用权利方或授权本地化渠道实际使用的名称，并核对对应作品、地区和版次。没有官方中文译名就保留原名，不自行翻译、音译，也不把社区译名写成官方名称；原语言资料足以满足语言资料要求。

非官方译名需要模型和界面提供名称级 `nonofficial` 标记。目前 `Translation` 只有 title、summary、body、aliases，没有该标记，因此暂不录入非官方译名；不要伪造字段或把标记拼进名称。已有缺证名称按具体任务核实，不自动批量清空。

## 当前证据

来源位于修订记录，新提交的 `source_refs` 选择操作来源，可用 JSON Pointer 对应字段，回读时体现为 `pointers`。无指针表示支撑本次操作；历史 `scope="commit"` 只表示整笔提交的来源池。

按版本确定当前快照；追查某字段时查看实际修改它的修订，最新修订的来源不会自动覆盖未改字段。API 接受载荷只证明格式合法，不证明来源支持结论。

## 收录、署名与图片

- 商品曲目表支持本版收录，品番不证明独立录音或母版，也不作为录音版本名。艺人简介提到动画歌曲，不自动证明整张专辑是原声带。
- 共同署名逐人保留，职位与适用曲目、录音或版次对应；初回封入、渠道、数量和随机条件按原意记录，不能省略后改变含义。
- 图片核对具体对象、版次与图源。`Picture.source` 是来源，`asset_id` 是存储绑定，都不代表转载许可；权利结论按实际材料说明。

## 原始资料保留

URL/citation、抓取时间与哈希不会自动归档网页原文，`tracklist_excerpt` 等提取摘要也不是完整原始资料。用户要求完整保留时，区分已存事实、来源引用、已归档原文和未映射信息；这些说明不增加普通编辑的前置步骤。
