# 数据核对参考（可选）

仅在用户要求审查或排查具体问题时选用。普通编辑无需跑审计、达到完整度或逐项完成清单。

- **身份与层级**：比较内容身份、编号和归属，区分 Work、Expression、Release 与收录位置；同名不等于同一对象。
- **来源与表述**：核本次结论是否超出来源。保留共同署名及版次、初回、渠道、数量等限定；中文名称按[来源说明](source-policy.md#中文译名)处理。
- **结构与关系**：检查本次涉及的 subjects、contents、方向和上下文；没有证据的部分可留待以后补充。
- **实际结果**：回读本次修改与相关引用，说明已生效、待审、冲突或尚未核实的部分。
- **用户要求完整性结论时**：对照约定范围指出已保存事实与遗漏；区分原始资料归档和结构化录入，不用实体数代替覆盖程度。

质量 API 的 `complete` 只表示返回的 `checks` 未发现问题；其结果不阻止编辑、提交或应用，也不代替人工语义判断。只读工具见[工具索引](../scripts/tools/README.md)。
